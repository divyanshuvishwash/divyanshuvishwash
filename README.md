## ⭐ Featured project

### ⏱️ Doom-Timer: real-time distraction cost tracker

> Every second of distraction has a price tag. Enter your hourly wage, pick what is stealing your time, and watch the money burn live.

![Doom-Timer screenshot](https://raw.githubusercontent.com/divyanshuvishwash/doom-timer/main/screenshot.png)

- Live cost counter: `cost = elapsed hours x hourly wage`, updated every 100 ms
- Burn meter, efficiency score, daily total and annual projection
- Session history saved in a **SQLite** database through a **Node.js** REST API
- Downloadable plain-text "Doom Report"
- Built with plain **HTML, CSS and JavaScript**, with no libraries or frameworks

**Tech:** HTML · CSS · JavaScript · Node.js · SQLite
